# Curo Reader

Lector y editor de PDF para uso interno de CURO Group.

- Leer, buscar, ampliar y ver miniaturas
- Añadir y corregir texto, notas, resaltar, dibujar, recuadros y tapar
- Firmar e insertar imágenes
- Rellenar formularios
- Girar, ordenar, borrar e insertar páginas; combinar varios PDF
- Guardar una copia editada

Los PDF se procesan en el navegador: no se suben a ningún servidor.
Página estática (index.html + logo.png), publicada en Vercel.
